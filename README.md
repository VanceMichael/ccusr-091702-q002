# 营养宣称证据台账

本服务用于菜单营养宣称的证据版本、签发与撤回影响。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：机构、营养师、事实、指南版本、评审快照、签发结论、复核任务。

已签发结论绑定当时的证据快照；指南撤回不改写旧结论；冲突结论需由不同审核员复核；机构间资料默认隔离。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/nutrition_evidence.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
